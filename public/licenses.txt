Mahonia — third-party notices
=============================

Served at https://mahonia.app/licenses.txt

WHY THIS FILE EXISTS. Mahonia bundles its JavaScript dependencies rather than
loading them from a CDN. That is a security choice, not a packaging one: a list's
edit capability lives in the URL fragment, and any third-party <script> in the
page can read location.hash, so a CDN tag would be a capability leak (see
config/security.ts). The consequence is that the site redistributes those
libraries' code, and MIT and BSD both require their copyright notices to travel
with a redistribution.

The minifier strips the banner comments those libraries ship with — Leaflet's
`/* @preserve */` header does not survive into the built chunks — so this file
carries the notices instead. It lives in public/, which means it is deployed
alongside the JavaScript it describes.

MAINTENANCE. Add an entry when a dependency's code starts reaching the BROWSER.
Server-only packages (satori, resvg-js, @simplewebauthn/server, drizzle-orm, the
Neon and PGlite drivers, @upstash/redis) are not redistributed by serving this
site and are deliberately not listed. The Inter subset used by the social-card
renderer is server-only too, and ships its OFL text at
server/assets/fonts/LICENSE.txt.

The full dependency graph, with each package's declared license, is in
package-lock.json.
